STEP 1: Extract & Test
  1. Extract the zip file to a folder
  2. Double-click "index.html" to open in your browser
  3. Try adding items, searching, adjusting cart
  4. Click "Chat" button to test WhatsApp link

STEP 2: Customize (Update Your Details)
  
  IMPORTANT - Update these 3 things:
  
  a) WhatsApp Number
     Find: 201286460004
     Replace with: YOUR WhatsApp number (with country code)
     Where: index.html and script.js
  
  b) Menu Items
     Open script.js → Find "menuData" object
     Update dish names, prices, descriptions
     Add/remove items as needed
  
  c) Restaurant Name
     Edit header in index.html if needed

STEP 3: Go Live (15 Minutes)
  
  Option A: Vercel (RECOMMENDED)
    1. Go to vercel.com
    2. Upload files or connect GitHub
    3. Click Deploy → Done! Live in seconds
    URL: na2na2.vercel.app
  
  Option B: Netlify
    1. Go to netlify.com
    2. Drag & drop your files
    3. Site goes live immediately
  
  Option C: GitHub Pages
    1. Create GitHub account
    2. Create repository
    3. Upload files
    4. Enable GitHub Pages
    URL: yourusername.github.io/na2na2
